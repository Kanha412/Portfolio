# frontend/

Angular 22 SPA for the portfolio.  
**See [root README](../README.md) for full setup, deployment, and content editing guide.**

---

### Quick start

```bash
npm install
cp src/environments/environment.template.ts src/environments/environment.ts
# fill in geminiApiKey and formspreeUrl in environment.ts
npm start   # → http://localhost:4200
```

### Build

```bash
npm run build:prod    # production build → dist/frontend/browser/
```
